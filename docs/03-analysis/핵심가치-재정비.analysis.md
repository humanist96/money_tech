### 총평

계획의 **골격은 충실히 이행**되었다. CUT/MERGE 판정은 거의 전부 실행됐고(페이지 22개 판정 중 17개 완전 일치, 리다이렉트 12경로 전부 존재), 트랙 B의 핵심 전제인 **point-in-time 가격 조회**는 코드 레벨에서 확실히 복구됐으며, 트랙 C의 **하드 게이트는 전역 플래그가 아닌 조인 술어로 구조적으로 강제**되어 계획보다 안전하다.

그러나 갭 분석 시점에 **핵심가치 지표를 직접 훼손하는 결함 3건**이 남아 있었다:

1. **BTC가 BTC로 벤치마킹** — `resolve_benchmark()`가 자산 코드를 보지 않아 BTC 예측의 초과수익이 항상 0 → 전량 `push` → 표본에서 조용히 탈락. 계획 §3.2가 명시적으로 경고한 지점.
2. **리더보드 `n_effective >= 10` 필터 누락** — wilson_low 정렬만 있어 n=1 채널이 1위를 점할 수 있었다. 계획 §3.5에 명시된 항목.
3. **v1/v2 지표 공존** — 리더보드는 v2, 채널 상세·대시보드·portfolio API는 더 이상 갱신되지 않는 `direction_score` 사용.

> **분석 직후 조치**: ①②는 갭 분석 당일 수정하고 전체 재평가를 실행했다(§10 참조). ③은 P0로 남아 있다.
