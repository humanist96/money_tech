## 핵심가치-재정비 (core-refocus)

기능 축소 + 정량 분석 재구축 + `/movers` 신설. 계획서가 설계 문서를 겸했다(별도 design 문서 없음).

**측정 이력**: 79.9%(초판) → 85.0%(3차 정정) → 85.7%(4차) → 89.3%(5차) → **90.0%(6차)**
150항목 기준 일치 120 / 부분 30 / 미구현 0.

**주요 성과**
- 평가 파이프라인 3개월 정지(2026-05-13 ~) 복구 — 확정 판정 5,490 → 10,255건, 랭크 채널 1 → 70개
- 벤치마크 오배정 2건 교정 — 시장 매핑 커버리지 18% → 100%(G40), 미국 종목 KOSPI 판정 859 → 0건(G41)
- 자산군 스코프 확정 — 부동산 제외, 국내 주식 중심(Phase A5). 공개 API 노출도 차단
- 페이지 22 → 12개, 리다이렉트 12경로

**핵심 결론**: 매핑 결함을 모두 교정한 뒤 전체 적중률 40.6%, 시장을 유의하게 상회하는 채널은 69개 중 3개(표본 n=11~19로 얇음). "검증된 크리에이터 우위는 아직 관측되지 않는다"가 현재 데이터가 지지하는 결론이며, 이를 신뢰구간·표본 배지로 화면에 드러낸 것이 제품의 차별점이다.

**인계 사항 — 잔존 P1 5건** (새 PDCA 사이클로 다룰 것)
